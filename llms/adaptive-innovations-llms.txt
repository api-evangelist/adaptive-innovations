## For agents: there is no API to call

Adaptive Innovations is a care-delivery company, not an API vendor. As of 2026-09-07:

- No developer portal, API reference, getting-started guide, SDK, CLI, or Postman collection.
- No OpenAPI, AsyncAPI, GraphQL SDL, JSON Schema, or Protobuf published anywhere.
- No MCP server, no A2A agent card, no /llms.txt, no /.well-known/ document on any host.
- No webhooks, no status page, no changelog, no public rate limits, no pricing or plans.

One API host exists but is not a product surface: `https://api.adaptive.co` runs a FastAPI
application (behind Istio/Envoy) that serves Adaptive's own iOS and Android app. It is not linked
from adaptive.co and was found by DNS resolution. `GET /health` returns 200; `GET /openapi.json`,
`GET /docs` and `GET /redoc` all return HTTP 401 `{"detail":"Not authorized"}`. The OpenAPI document
therefore exists but is private. Do not attempt to call it — it is a first-party backend for
patients and clinicians, not an integration surface.
